## Important boundaries

1. The test logs report `0.44.0rc1` and successful installation of its wheel, but **do not provide a cryptographic wheel hash** to tie the tested wheel byte-for-byte to a GitHub Release artifact. Release packaging should use the GitHub CI artifact built from the selected tag/commit.
2. The **new RC-specific** ZIP contains no fresh PDF rendering, screenshots, full visual-layout comparison or 24-scenario × 2-format PDF acceptance output. The historical 48/48 native PDF-export results belong to a **different earlier build** and must not be presented as this release candidate's results.
3. Native automation was exercised on the user-provided Windows host; hosted GitHub Actions runs portable and package checks, not Microsoft Word/Hancom COM.
4. Unsupported cross-format conversions and pixel-identical Word/Hancom pagination are not warranted.
5. These are automated test results; no statement is made that every API capability is supported or visually pixel-identical.
