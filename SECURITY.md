# Security Policy

PyWPDoc parses complex document ZIP/XML packages. Treat files from unknown senders as untrusted; open them in appropriately sandboxed/least-privilege environments. Please avoid submitting confidential documents to public issues. For sensitive reports, contact repository maintainers privately using the GitHub repository's security reporting interface if available. Do not claim automatic protection from every malicious Office document.

For normal bugs, open an issue with a minimal synthetic reproducer and your Python, Word or Hancom version.
